# 🎨 美术风格指南 · Drive-Thru Survivors

## 视觉基调

**暖色明亮卡通矢量风（Warm Cartoon Vector）**，继承自 codex-6.1-sol 的已验证美术风格。

关键词：圆润玩具感、高对比度、清晰棕色描边、柔和投影、麦当劳红金点缀。

> 参考气质：皮克斯《赛车总动员》的活泼 × 任天堂的干净可读性 × 麦当劳品牌的暖色温度。

## 程序化资产（零外部依赖）

所有游戏画面必须用 **Phaser Graphics API / Canvas API** 程序化绘制。不依赖任何外部图片、图集、字体或音频文件。

### 赛车

```
绘制方式：Phaser.GameObjects.Graphics

玩家赛车（俯视）：
├── 车身：圆角矩形 40×60px，填充 #e75239，描边 #754329（2px）
├── 车窗：半透明浅色矩形 24×15px，位于车身上部 1/3
├── 车轮：4 个小黑色圆角矩形 8×14px，分布在车身四角
├── 尾翼：深色矩形 30×4px，位于车身底部
├── 大灯：2 个黄色小圆 r=3px，位于车身顶部两侧
└── 总尺寸约 50×70px

AI/敌方赛车：同样造型，填充 #80c6c3（天青蓝）或 #d93025（危险红）
```

### 赛道

```
绘制方式：Tiled 重复或 Graphics 绘制

赛道（纵向滚动）：
├── 三车道公路：总宽 240px
│   ├── 左右边线：白色实线 2px
│   ├── 车道分隔：白色虚线（8px 线段 + 16px 间隔）
│   └── 路面填充：#5c6564
├── 路肩：浅灰色 10px 宽带
├── 草地：#bed994 填充 + 随机深色草丛点缀
├── 护栏：棕色 #754329 矩形条，碰撞用
└── 装饰（确定性放置在草地上，见「城市风貌与地标」）：
    ├── 圆顶树：层叠半圆绿冠 + 棕色树干（复用 codex-6.1-sol 的 #roundTree 造型）
    ├── 积木楼：带侧影的 2.5D 矮平房（复用 codex-6.1-sol 的 #building 造型）
    └── 麦当劳门店：红顶棚 + 黄色拱门标识（#cafe 造型，每周期在赛道两侧各出现一间）
```

### 得来速站点（当前实现）

原三车道在站点附近转为「左侧两条通行车道 + 右侧维修车道」，不增加路面宽度。右侧车道与主路平行，以短段奶油色低隔离墙区分；墙前后留出变道口，用克制的黄色斜纹提示分流，墙外不叠加大型路面。停车格与棋盘格标明维修工位，服务亭位于外侧路缘外的小块奶油色地坪上，红色条纹雨棚、凹进服务窗、菜单和扳手挂牌同时表达餐品补给与赛车维修。取消入口门架，避免立柱横挡车道。

赛车在隔离墙开始前自动进入右侧车道，镜头向右平移展示停靠区；出站沿原车道继续前进，通过隔离墙后恢复三车道驾驶。停车提示位于底部，避免遮住服务窗和车辆。导向牌、箭头、服务亭和隔离柱纹理均在启动时生成与缓存；墙体与地面标线共用赛道投影绘制。

## 粒子特效清单

所有粒子使用**对象池**预分配，运行时零内存分配。

| 特效 | 触发条件 | 粒子描述 | 生命周期 |
|------|----------|----------|----------|
| **漂移烟雾** | 漂移中，每帧 | 灰白色半透明圆，从后轮喷出，alpha 0.6→0 | 0.5s |
| **漂移火花** | 漂移中，按蓄力等级 | 蓝/橙/紫色小光点，后轮交替闪烁 | 0.2s |
| **氮气喷焰** | 冲刺中 | 橙色→蓝色火焰粒子，从排气管喷出 | 0.3s |
| **碰撞火花** | 撞墙/撞敌人 | 黄色小光点向碰撞方向散射 | 0.3s |
| **击杀爆炸** | 敌人被消灭 | 敌人颜色的碎片 + 橙色火焰，四散扩射 | 0.5s |
| **金币吸附** | 金币被拾取 | 金色拖尾沿贝塞尔曲线飞向赛车 | 0.3s |
| **受伤闪烁** | 玩家被碰撞 | 屏幕边缘红色渐变叠加层，快速闪烁 | 0.5s |
| **速度线** | 车速 > 70% | 白色半透明径向线条从边缘向中心 | 持续 |
| **BOSS 清场** | BOSS 被击杀 | 全屏白色闪光 + 大量金色碎片 | 1.0s |
| **出站冲刺** | 离开商店 | 速度压缩线 + 赛车周围金色光环 | 2.0s |

### 轮次天气（4 轮氛围渐强）

一局的四轮依次走「晴朗 → 多云 → 黄昏 → 雨夜」（`src/systems/weather.ts` 对城市配色做确定性叠加），进站开新一轮时整体切换。雨夜另叠加约 36 条轻量雨丝（与速度线共用 Graphics），车道线反向提亮表达路面湿反光。HUD 波次区显示「第 N 轮 · 天气」标签。

## 餐品变体美术（2026-10-25 新增）

商品名不再共用一张贴图：`src/data/foodArt.ts` 为 13 个武器家族定义 28 个变体（双层巨堡/麦辣红堡/鳕鱼堡、长薯/扭扭薯/薯饼、可乐/雪碧/芬达……），购买时按商品名确定性解析——关键词优先（巨无霸→双层堡、扭扭→卷薯、麦旋风→旋风杯），未命中回退名称哈希，线上真实菜单任意名字同样稳定落位。

- 商店卡片、武器槽图标与游戏内弹幕同源：Boot 烘焙贴图导出 dataURL 供 DOM 使用，弹幕按 `bulletScale` 缩回原尺寸量级，商店清晰度不损失。
- 辅助光环类（可乐喷泉/冰冻射线/回复光环/护盾甜筒/环绕甜筒）颜色改读变体 tint；地雷从 Graphics 三角升级为麦乐鸡盒/麦辣鸡翅贴图。
- 弹幕保留「Lv3+ 金色充能」tint 作为成长信号，叠加在变体原色之上。
