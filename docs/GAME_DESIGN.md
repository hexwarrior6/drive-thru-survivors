# 🎮 详细玩法设计 · Drive-Thru Survivors

## 1. 驾驶系统（Mario Kart 血统）

### 视角与画面

- **俯视 2D 或 45° 2.5D**，赛车在赛道上行驶
- 赛道自动向下滚动（世界向玩家推进），赛车位于画面中下方 1/3 处
- 画面风格：暖色卡通矢量风（详见 [ART_STYLE.md](ART_STYLE.md)）
- 赛道两侧有装饰：霓虹灯得来速门店、卡通建筑、路灯、树木

### 操控方式

| 操作 | 手机 | 电脑 |
|------|------|------|
| **转向** | 左右滑动 / 虚拟摇杆 / 左右大箭头按钮 | ← → / A D |
| **漂移** | 按住漂移按钮 + 转向 | 按住 Shift + 转向 |
| **加速冲刺** | 点击冲刺按钮（消耗氮气） | Space |
| **使用主动道具** | 点击道具图标 | Q / E |

手机控件至少 48×48 CSS px，冲刺按钮建议 64-72 px。底部安全区不被控件遮挡。提供大箭头作为滑动替代。

### 漂移物理模型（Dual-Vector）

核心公式：**航向向量** ($\vec{H}$) 与**速度向量** ($\vec{V}$) 分离。

```
每帧物理更新：
1. 将速度分解为车身前向分量和横向分量
2. 横向分量乘以摩擦系数：
   - 正常行驶：grip = 0.88（横向阻力大，抓地力强）
   - 漂移中：grip = 0.98（横向阻力小，车尾甩出去）
3. 重新合成速度向量
4. 释放漂移时，slerp 将速度向量平滑回正（factor 0.15）
```

**漂移蓄力三级系统**：

| 漂移时长 | 火花颜色 | 释放加速 |
|----------|----------|----------|
| 0.5-1.0s | 🔵 蓝色 | +15% 速度脉冲 |
| 1.0-2.0s | 🟠 橙色 | +25% 速度脉冲 |
| 2.0s+    | 🟣 紫色 | +40% 速度脉冲 |

漂移时车身旋转速度快于速度向量变化，给玩家"方向盘先行"的即时反馈感。

### 速度与氮气

- 赛车有**最高速度**封顶，按住加速渐近最高速
- **自然减速**：松开加速键时按摩擦系数减速，不是立即停止
- **氮气条**（0-100）：波间商店可补充；击杀部分敌人掉落蓝色氮气瓶
- **冲刺**：消耗 20 氮气，2 秒内速度提升 50% + 撞击伤害翻倍
- 冲刺期间车尾喷出橙蓝火焰粒子，画面微微缩远（模拟 FOV 扩展）

## 2. 战斗系统（Brotato 血统）

### 自动射击机制

**当前基础玩法（阶段 2 调整）**：驾驶负责前方避障，车尾炮台负责打追兵。基础炮台不主动锁定路锥和购物车，仅对 360 道路单位内最近的疯狂骑手自动开火，每 0.38 秒发射一轮 3 颗散弹、每颗伤害 12，并预判目标移动。近距离同一轮可命中多颗，追兵聚拢时可同时击中多个；远处散弹散开，驾驶需要在输出距离和碰撞风险之间选择。炮台独立旋转，骑手绕到侧面或超车后仍可锁定。冲刺提供真正的脱身窗口，骑手速度不会随赛车冲刺抬高。以下前方、环绕等规则用于后续可装备的不同武器。

- 赛车最多装备 **6 个武器槽位**
- 每个武器有独立射击冷却计时器
- 武器**自动瞄准并射击**：
  - 前方武器：瞄准前方最近的敌人
  - 环绕武器：攻击最近的敌人（360°）
  - 后方武器：瞄准身后最近的追踪者
- 玩家**完全不需要手动瞄准**，只需要专注驾驶和走位
- 关键设计原则（来自 Brotato）：**认知卸载**——自动攻击释放玩家 100% 心理带宽用于空间意识和走位

### 速度 = 力量（核心融合点）

- 赛车当前速度影响战斗能力：
  - **撞击伤害** = 基础伤害 × (当前速度 / 最高速度)
  - **漂移加速后撞击** = 撞击伤害 × 2（蓝级）/ × 2.5（橙级）/ × 3（紫级）
  - **弹丸初速** = 基础弹速 + 赛车速度的 30%
- 这意味着：**开得越快、漂移越多 = 杀伤力越强**。赛车和战斗不是两个游戏，而是同一个。

### 敌人类型

#### 基础敌人（波次 1-3 就出现）

| 敌人 | 造型 | 行为 | 血量 | 危险度 |
|------|------|------|------|--------|
| **路障锥** | 橙色三角锥 | 静止/缓慢下移，地形障碍 | 低 | ★ |
| **叛逆购物车** | 灰色方形+轮子 | 从赛道侧面冲入，中速横穿 | 中 | ★★ |
| **疯狂骑手** | 深红小型摩托 | 2–3 名成组从车后追来，转向有惯性；约 394 道路单位/秒，冲刺能拉开距离 | 80 | ★★ |

#### 精英敌人（波次 4+ 出现）

| 敌人 | 造型 | 行为 | 血量 | 危险度 |
|------|------|------|------|--------|
| **垃圾车** | 深绿大型方块 | 缓慢前进但不可推动，需绕开或击毁 | 高 | ★★★ |
| **油罐车** | 银色长方形 | 被击毁时爆炸，伤害周围所有单位（含玩家） | 高 | ★★★ |
| **逆行赛车** | 紫色赛车 | 高速从前方冲来，需要及时变道 | 中 | ★★★★ |

#### BOSS（每 5 波出现）

| BOSS | 造型 | 攻击模式 | 血量 |
|------|------|----------|------|
| **霸王卡车** | 占据 2 车道的巨型卡车 | 左右摇摆碾压 + 从后方投掷小怪 | 极高（需要整波时间输出） |

### 碰撞与伤害

- **敌人碰到玩家**：造成车况伤害 + 屏幕边缘红色闪烁 + 0.5 秒无敌帧
- **玩家撞击敌人**（高速）：对敌人造成撞击伤害 + 弹飞效果
- **撞墙**：弹性反弹 + 少量车况损失 + 火花 + 屏幕微震 + 短暂减速

### 掉落系统

击杀敌人后掉落（概率）：

| 掉落物 | 造型 | 效果 | 掉率 |
|--------|------|------|------|
| **金币** | 金色小圆，旋转 | +虚拟货币（商店购买用） | 100% |
| **氮气瓶** | 蓝色小瓶 | +20 氮气 | 15% |
| **修理零件** | 绿色扳手 | +5 车况 | 10% |
| **磁铁** | 红色 U 型 | 10 秒内吸附范围翻倍 | 5% |

- 掉落物在赛车附近 **80px 内自动吸附**（贝塞尔曲线飞向赛车 + 金色拖尾）
- 追兵击杀掉落的金币自动飞回车身；路障掉落仍使用 80px 磁吸，避免强迫玩家回头领奖
- 超出屏幕的掉落物消失

## 3. 波次系统

### 波次结构

- 每波 **45-60 秒**（随波次递增）
- 波次开始时：HUD 显示 **"WAVE 3"** 大字从中间弹出、放大、渐隐（0.8 秒）
- 敌人按预定模式从赛道上方和两侧刷出
- 波次结束条件：计时结束（不要求全灭）

### 难度曲线

| 波次 | 定位 | 内容 |
|------|------|------|
| 1-3 | **教学期** | 只有路障锥和少量购物车，让玩家熟悉操控和武器 |
| 4-7 | **成长期** | 引入精英敌人，敌人密度增加，开始需要走位和漂移 |
| 8-12 | **挑战期** | 混合大量敌人，逆行赛车出现，BOSS 登场 |
| 13+ | **极限期** | 高密度混合刷怪，多类精英同时出现，考验 Build 和操作 |

### 难度递增方式（优先级）

1. **增加敌人类型组合**：多种敌人混合出现
2. **增加路况复杂度**：障碍物和金币的位置更刁钻
3. **增加门店间距**：更久才能到商店补给
4. **适度加快敌人速度**：但保证始终有可通行路径和反应窗口
5. **不要**：无限加速到超出人类反应、不可避免的死亡

## 4. 得来速商店（Shop Phase）

### 进站流程

1. 波次计时结束 → 赛道前方出现**金拱门霓虹灯标识**（黄色 M 字 + 发光闪烁动画）
2. 赛车自动减速，驶入侧方得来速车道（过场动画，约 1 秒）
3. **暂停所有战斗和道路滚动**
4. 平滑过渡到商店 UI（面板从底部滑入或淡入）

### 商店卡片设计

每波商店展示 **3 张餐品武器卡** + **1 个维修选项**。

卡片内容结构：

```
┌────────────────────────────┐
│  🍔 [MCP 真实商品名]         │  ← 来自 MCP 快照
│  ═══════════════════════   │
│  [武器名] Lv.[等级]         │  ← 游戏武器映射
│                             │
│  [一句话效果描述]            │  ← 玩家立刻知道干啥用
│                             │
│  伤害: ████████░░ 80        │  ← 可视化属性条
│  射速: ███░░░░░░░ 30        │
│  范围: █████░░░░░ 50        │
│                             │
│  已有 Lv.1 → 合成 Lv.2!     │  ← 如果已装备同名武器
│  Lv.2: +穿透效果             │  ← 升级后新增能力预览
│                             │
│       ¥ 28.00               │  ← MCP 真实参考价（虚拟货币）
│  [  购  买  ]               │
└────────────────────────────┘
```

### 购买规则

- 武器槽未满（<6）：直接加入空槽
- 武器槽满（=6）：点击购买 → 弹出 "替换哪一个？" → 选中旧武器 → 确认替换
- 已有同名武器且未满级：自动合成升级（不占新槽位）
- 已有同名且满级（Lv.3）：卡片标注"仅即时效果"，不能继续升级
- 可以不买直接离开（点"出发"按钮）

### 维修选项

- 标为**"游戏服务"**（非 MCP 商品，明确区分）
- 固定费率：花费金币回复固定车况
- 每站只能维修一次

### 出站冲刺

- 点击"出发"后：
  1. 商店面板滑出
  2. 赛车从得来速车道驶出
  3. **2 秒无敌 + 自动加速**（"出站冲刺"）
  4. 画面周围出现速度压缩线
  5. 下一波正式开始

## 5. 经济系统

### 收入来源

| 来源 | 数量 | 说明 |
|------|------|------|
| 击杀普通敌人 | 1-3 金币/个 | 基础收入 |
| 击杀精英敌人 | 8-15 金币/个 | 奖励主动出击 |
| 击杀 BOSS | 30-50 金币 | 大额奖励 |
| 波次完成奖励 | 10 + 波次数×2 | 保底收入 |
| 赛道金币收集 | 1 金币/个 | 鼓励走位收集 |
| 连击奖励 | 每 10 连击 +5 金币 | 奖励持续输出 |

### 支出

| 支出 | 价格范围 | 说明 |
|------|----------|------|
| 餐品武器 | MCP 真实报价映射 | 虚拟消费，价格有差异 |
| 车辆维修 | 固定费率 | 游戏系统服务 |

### 经济张力设计原则

- 基础收入能覆盖**要么维修、要么买一件武器**，但不能全都要
- 高操作（多连击、多金币收集）的玩家能同时维修和升级
- 不强制花光所有钱，留钱是有效策略（为下波更好的武器攒钱）
- 价格来自 MCP 真实报价的映射（整数分转虚拟币），但绝不涨价或打折来操纵难度

## 6. 车况与失败

### 车况（0-100）

- **损失来源**：
  - 敌人碰撞（-5 ~ -15 取决于敌人类型）
  - 撞墙（-3）
  - 冲刺期间额外磨损（-1/秒）
- **回复来源**：
  - 商店维修（+20 ~ +40）
  - 修理零件掉落（+5）
  - 特定被动武器效果（如苹果派光环）

### 失败流程

1. 车况降至 **20 以下**：HUD 车况条变红 + 赛车冒烟 + 警告音效
2. 车况归零：进入**紧急滑行**（3 秒，速度递减，禁止冲刺）
3. 紧急滑行结束仍未回复：**抛锚** → 赛车停下冒黑烟 → 切入结算画面
4. 如果紧急滑行期间拾取到修理零件：回复少量车况，继续比赛

### 失败反思

结算画面应清晰展示：
- "你在第 X 波因为 [连续碰撞/冲刺过度/...] 导致车况耗尽"
- "本局最高车况出现在第 Y 波后"
- "建议：尝试 [装备回复类武器/减少冲刺/多进店维修]"

## 7. 分数与重玩

### 结算画面内容

- **最远距离**（公里数，主要成绩指标）
- **存活波次**
- **总击杀数** / **最高连击数**
- **本局 Build 展示**（6 个武器图标 + 各自等级）
- **经济统计**：总收入 / 总支出 / 最终余额
- **操作评价**：漂移次数 / 紫级漂移占比

### 重玩动力

- **不同 MCP 菜单** → 不同可用武器池 → 不同 Build 策略
- **不同赛车选择** → 不同初始被动 → 不同开局节奏
- **Build 探索欲** → "全汉堡重火力流" "全饮品控制流" "经济流攒钱后期爆发"
- **操作提升** → "这次漂移更多，连击更长，跑得更远"
- **有意义的后悔** → "刚才应该选薯条而不是鸡块，散射在密集敌群里更强"

## 环境多样性与美术辨识（2026-10-25）

- **城市即风貌**：每座城市确定性映射六种原型之一（都市霓虹/滨海大道/江南水乡/北国秋色/山城层峦/古都风华），决定赛道配色、地平线形态与路边装饰组合；金拱门店每周期固定入列。12 座主要城市（上海/北京/广州/深圳/杭州/重庆/成都/武汉/西安/天津/长沙/哈尔滨）在赛道远端拥有专属地标。同名城市永远同貌，不同城市即使同原型也有不同的装饰排布。
- **四轮天气**：一局的四轮走「晴朗 → 多云 → 黄昏 → 雨夜」，难度推进与氛围收紧同步；进站时切换，HUD 显示当前天气。
- **逐商品美术**：同名武器不再共用贴图——巨无霸/麦辣/鳕鱼堡、可乐/雪碧/芬达、长薯/扭扭薯/薯饼等 28 个变体按商品名确定性分配，商店展示与场内弹幕同源；无关键词的真实菜单名按哈希稳定落位。
