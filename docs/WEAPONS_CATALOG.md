# ⚔️ 武器图鉴 · Drive-Thru Survivors

> 每一件麦当劳餐品都对应一种车载武器或被动能力。这是本游戏最核心的创新点。

## 武器系统规则

### 基本规则

- 赛车最多装备 **6 个武器槽位**
- 游戏开始时装备 1 个"基础豌豆枪"（不可升级，可被替换）
- 每次进入得来速商店，从 MCP 快照中随机抽取 3 个餐品作为可购买武器
- 武器一旦装备，**自动攻击**，玩家无需手动操控

### 升级系统

- **同名餐品合成**：购买已装备的同名武器 → 自动升级
  - Lv.1 → Lv.2：属性 +50%，**附加特殊效果**（如穿透、分裂、范围扩大）
  - Lv.2 → Lv.3：属性 +50%（在 Lv.2 基础上），**视觉变化**（金色描边、更大弹丸、更炫粒子）
  - Lv.3 为满级，无法继续升级
- 升级不占用新槽位

### 替换规则

- 武器满 6 槽后购买新武器：
  1. 点击"购买"
  2. 底部 6 个武器槽高亮，提示"选择要替换的武器"
  3. 点击要丢弃的旧武器
  4. 确认替换，旧武器消失，新武器入槽

## Build 构筑示例

### 🔥 "重火力流"

```
汉堡炮台 Lv.3 + 薯条散射枪 Lv.2 + 鸡块地雷 + 咖啡涡轮 + 回复光环 + 可乐喷泉
```
策略：前方穿透高伤 + 扇形覆盖 + 后方陷阱 = 全方位输出，咖啡加速跑得更远，回复续航。

### 🧊 "控制流"

```
冰冻射线 Lv.3 + 可乐喷泉 Lv.2 + 薯条散射枪(减速) + 甜筒护盾 + 咖啡涡轮 + 鸡块地雷
```
策略：冻住前方 + 推开侧面 + 减速后方 = 永远没有敌人能碰到你，护盾保底。

### 💰 "经济流"

```
回复光环 Lv.3(吸引掉落) + 咖啡涡轮 Lv.2 + 甜筒护盾 + 可乐喷泉 + 汉堡炮台 + 薯条散射枪
```
策略：靠被动续航和护盾减少维修支出，吸引掉落多捡金币，积攒到后期一次性升级多个武器。

### 🏎️ "漂移战神流"

```
辣椒喷射器 Lv.3 + 咖啡涡轮 Lv.3 + 绝境提速 + 可乐喷泉 + 回复光环 + 任意
```
策略：全程高速漂移，尾焰灼烧追兵，速度被动叠满，低血反而更快。需要极高操作技术。

## 武器平衡设计原则

1. **没有"必选"武器**：每种武器在特定情境下都有价值
2. **升级有实质变化**：不只是数字 +50%，每次升级都带来新的战术选择（穿透、分裂、冻结连锁等）
3. **类别有取舍**：全选攻击类 → 伤害高但脆；全选防御类 → 苟活但输出低打不过后期敌人
4. **速度加成有封顶**：被动速度总计不超过 +25%，保证反应窗口
5. **回复有上限**：不能通过叠加回复实现"永远不死"
6. **MCP 数据决定武器池**：不同门店、不同菜单 = 不同可用武器组合，每局体验自然不同
