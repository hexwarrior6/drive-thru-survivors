# ⚔️ 武器图鉴 · Drive-Thru Survivors

> 每一件麦当劳餐品都对应一种车载武器或被动能力。这是本游戏最核心的创新点。

## 武器系统规则

### 基本规则

- 赛车共 **5 个武器槽位**：前炮台 ×1、后炮台 ×1、辅助位 ×3；另有 1 门**内置后置散弹炮**（不占槽、不可拆）
- 每波结束自动驶入得来速商店，商品来自 MCP 快照的真实门店菜单
- 武器一旦装备，**自动攻击**，玩家无需手动操控

### 升级系统

- **同名餐品合成**：购买已装备的同名武器 → 自动升级
- 武器满级为 **Lv.5**；Lv.3 起弹丸获得金色"充能"视觉，高阶附带穿透/弹丸放大等强化
- 升级不占用新槽位

### 替换规则

- 武器满 6 槽后购买新武器：
  1. 点击"购买"
  2. 底部 6 个武器槽高亮，提示"选择要替换的武器"
  3. 点击要丢弃的旧武器
  4. 确认替换，旧武器消失，新武器入槽

## 🧂 酱料系统（Boss 掉落 · 全局强化）

> 霓虹深渊式强化堆叠：击败霸王卡车（第 5/10/15 波）后驶入得来速，窗口先递上**三包酱料任选其一**（可跳过换 15 金币）。酱料挂上餐车即对**全部武器**生效，一局最多堆 3 包，12 包池 ≈ 220 种组合——这是"再来一局"的核心动力。

| 酱料 | 效果 | 生效层 |
|---|---|---|
| 烧烤酱 | 巨型弹：伤害×1.35、弹体×1.6、弹速×0.75、命中击退 | 弹体 |
| 跳跳糖 | 弹射：命中后飞向 280px 内下一个敌人，最多弹 2 次 | 弹体 |
| 甜酸酱 | 弹墙：脱靶弹丸撞路沿反弹，存活时间×1.4 | 弹体 |
| 番茄酱 | 爆破：命中点 90px 范围溅射 55% 伤害 | 弹体 |
| 芥末酱 | 连锁：电击 170px 内 2 个邻近敌人各 40% | 弹体 |
| 辣椒酱 | 灼烧：命中附着 3s、每秒 20% 命中伤害 | 调味 |
| 蛋黄酱 | 粘滞：命中减速 40% 持续 1.5s | 调味 |
| 樱桃酱 | 暴击：25% 概率 ×3 伤害（持有后弹丸常显金色） | 调味 |
| 蜂蜜芥末 | 吸血：武器击杀 +1 车况 | 调味 |
| 椒盐 | 拾金：武器击杀 +1 金币 | 调味 |
| 苹果酱 | 磁吸：金币拾取范围 +60% | 辅助 |
| 奶油咖啡酱 | 疾射：全武器射击间隔×0.87 | 调味 |

**规则要点**

- 「弹体」只作用于弹丸类武器（后散弹/汉堡/薯条/飞弹/僚车弹）；「调味」作用于一切武器伤害（含可乐喷泉、冰冻射线、辣椒喷射、地雷、环绕甜筒）
- **车体冲撞伤害不吃酱料**；灼烧 tick、溅射、连锁等衍生伤害不再触发酱料（防递归）
- Boss 奖励三选一按波号确定性生成，同一局同一状态必然同组候选；进站存档恢复后奖励不丢
- 已装备的酱料显示在进站面板顶部的「酱料架」，并随存档持久化
- 第 20 波最终 Boss 直接结算，不发酱料

## 🍽️ 变体形态表（28 道菜 = 28 种打法）

> 每个菜品变体**固定绑定**一种战斗形态（同家族内两两不同）：买不同的菜就是买不同的武器，商店卡片直接写明形态与修正后数值。变体形态与酱料强化**叠加生效**（鳕鱼堡自带弹射 + 跳跳糖 = 弹得更欢）。「同款变体」的不同商品名可以互相喂养升阶；同家族不同变体则走替换换装。

## Build 构筑示例

### 🔥 "重火力流"

```
汉堡炮台 Lv.3 + 薯条散射枪 Lv.2 + 鸡块地雷 + 咖啡涡轮 + 回复光环 + 可乐喷泉
```
策略：前方穿透高伤 + 扇形覆盖 + 后方陷阱 = 全方位输出，咖啡加速跑得更远，回复续航。

### 🧊 "控制流"

```
冰冻射线 Lv.3 + 可乐喷泉 Lv.2 + 薯条散射枪(减速) + 甜筒护盾 + 咖啡涡轮 + 鸡块地雷
```
策略：冻住前方 + 推开侧面 + 减速后方 = 永远没有敌人能碰到你，护盾保底。

### 💰 "经济流"

```
回复光环 Lv.3(吸引掉落) + 咖啡涡轮 Lv.2 + 甜筒护盾 + 可乐喷泉 + 汉堡炮台 + 薯条散射枪
```
策略：靠被动续航和护盾减少维修支出，吸引掉落多捡金币，积攒到后期一次性升级多个武器。

### 🏎️ "漂移战神流"

```
辣椒喷射器 Lv.3 + 咖啡涡轮 Lv.3 + 绝境提速 + 可乐喷泉 + 回复光环 + 任意
```
策略：全程高速漂移，尾焰灼烧追兵，速度被动叠满，低血反而更快。需要极高操作技术。

## 武器平衡设计原则

1. **没有"必选"武器**：每种武器在特定情境下都有价值
2. **升级有实质变化**：不只是数字 +50%，每次升级都带来新的战术选择（穿透、分裂、冻结连锁等）
3. **类别有取舍**：全选攻击类 → 伤害高但脆；全选防御类 → 苟活但输出低打不过后期敌人
4. **速度加成有封顶**：被动速度总计不超过 +25%，保证反应窗口
5. **回复有上限**：不能通过叠加回复实现"永远不死"
6. **MCP 数据决定武器池**：不同门店、不同菜单 = 不同可用武器组合，每局体验自然不同
