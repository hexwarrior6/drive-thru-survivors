## 阶段 0：项目脚手架与基础环境搭建

### 🎯 目标愿景
为《Drive-Thru Survivors》建立规范、干净、零冗余的前端单页游戏工程与后端轻量网关脚手架，保证开发服务器、热重载与基础画布能够顺畅运行。

### 🛠️ 技术边界与约束
1. **构建工具与核心框架**：使用 Vite + TypeScript 严格模式。
2. **游戏引擎**：使用 Phaser 3（通过 npm 安装，启用 WebGL 模式，带 Canvas 降级）。
3. **资产策略**：100% 纯代码程序化渲染，**严禁引入外部未授权图片、字体或音频文件**。
4. **画布规格**：初始视口适配 9:16 或类似移动端/桌面兼顾分辨率（如 450×800 居中适配），背景底色设为 `#fcf3d9`。
5. **依赖隔离**：遵循 `docs/TECH_ARCHITECTURE.md` 中定义的目录结构。

### 📝 具体执行步骤
1. 初始化 `package.json`，安装 `phaser`, `typescript`, `vite`, `zod` 等依赖。
2. 配置 `tsconfig.json`（严格模式）与 `vite.config.ts`。
3. 创建 `src/main.ts`，初始化 `Phaser.Game` 实例。
4. 创建基础场景架构：
   - `BootScene.ts`：负责程序化生成基础几何纹理与缓存。
   - `TitleScene.ts`：标题画面原型。
   - `GameScene.ts`：游戏主循环承载场景。
5. 验证本地开发指令 `npm run dev` 正常启动无报错。

### ✅ 验收标准
- [x] 运行开发命令后可在浏览器中正常打开并展示 Phaser 画布。
- [x] 控制台无任何警告或未捕获异常。
- [x] 画面底色正确渲染为暖奶油黄（`#fcf3d9`）。
- [x] 视口具备窗口自适应缩放机制（Phaser Scale Manager: FIT 模式）。

## 阶段 1：街机驾驶物理与“游戏果汁”手感（核心重点）

### 🎯 目标愿景
实现丝滑、有推背感、有操控深度的 2D/2.5D 街机赛车。这是游戏成败的生命线。玩家必须能体验到：
- 顺滑的变道与转向响应
- 蓄力后带推背感的马里奥赛车式漂移三级冲刺
- 强烈的速度感与视听反馈（游戏果汁 Game Juice）

### 🛠️ 技术边界与约束
1. **物理模型**：遵循 `docs/GAME_DESIGN.md` 中定义的 **Dual-Vector 双向量模型**（航向向量 $\vec{H}$ 与速度向量 $\vec{V}$ 分离）。
2. **漂移手感**：
   - 漂移中横向摩擦系数降低，后轮产生明显侧向滑动。
   - 蓄力三级判定：
     - 0.5s~1.0s：蓝色火花（释放获得 +15% 速度脉冲）。
     - 1.0s~2.0s：橙色火花（释放获得 +25% 速度脉冲）。
     - >2.0s：紫色火花（释放获得 +40% 速度脉冲）。
   - 漂移释放时通过 `slerp` 将实际速度向量平滑回正，消除生硬抽搐。
3. **无外部资源程序化绘制**：
   - 使用 `Phaser.GameObjects.Graphics` 绘制红橙色卡通赛车（尺寸约 50×70px，圆角车身、双前灯、黑车轮、棕色轮廓线 `#754329`）。
   - 程序化绘制无限滚动的 3 车道沥青公路（`#5c6564` 配白色虚线）及路侧草地（`#bed994`）与树木积木楼。
4. **程序化音频与特效**：
   - 使用 Web Audio API 原生合成引擎轰鸣（随着速度 80Hz~200Hz 动态滑音）与漂移胎噪（白噪声 + 动态低通滤波）。
   - 实现漂移烟雾粒子、火花粒子与高速动态速度线。

### ✅ 验收标准
- [x] 键盘（WASD / 方向键 / Shift 漂移 / 空格冲刺）可顺畅控制赛车。
- [x] 移动端提供虚拟方向箭头/摇杆与独立漂移、冲刺按钮（响应尺寸 ≥ 48×48px）。
- [x] 漂移时车尾明显产生侧向偏移，并随着蓄力时间依序喷射蓝、橙、紫三色火花。
- [x] 释放漂移瞬间有明显的加速推力、后坐力微震与速度线延展。
- [x] 撞击路边护栏有弹性反弹、火花与 3~5px 屏幕轻微震动，绝不卡死穿墙。
- [x] 引擎声音随车辆速度动态高低起伏，无音频资源请求 404。

## 阶段 2：Brotato 式自动战斗与波次生存

### 🎯 目标愿景
在高速驾驶的基础上叠加紧张刺激的自动战斗体系。驾驶专注走位躲避与超车漂移，车载武器全自动索敌倾泻弹幕，享受群怪收割与爆破快感。

### 🛠️ 技术边界与约束
1. **认知卸载**：玩家**无需且不能手动瞄准**。系统自动选取射程范围内最危险或最近的敌人发起攻击。
2. **速度即力量**：
   - 赛车碰撞伤害动态挂钩当前绝对速度。
   - 漂移爆发期间撞击伤害成倍提升（紫级漂移冲刺撞击威力翻 3 倍）。
3. **对象池机制（零 GC 丢帧）**：
   - 预分配弹丸池（200+）、敌人池（100+）、掉落物池（50+）、粒子池（500+）。
   - 严禁在每帧 `update` 循环中 `new` 对象或创建闭包。
4. **敌人生成与波次推进**：
   - 实现 45~60 秒固定波次倒计时。
   - 实现 3 种基础敌人：路障锥（静态阻挡）、叛逆购物车（侧向冲切）、疯狂骑手（尾随追踪）。
   - 敌人被消灭时触发爆破碎片粒子，爆出金币并支持 80px 范围自动磁吸。

### ✅ 验收标准
- [x] 赛车装备的基础武器能够按固定攻速自动射击（玩法调整：后置炮台专打骑手追兵，前方障碍交给驾驶避让）。
- [x] 弹丸命中敌人后弹出平滑向上飘落的伤害数字（Damage Numbers）与受击闪白。
- [x] 击杀敌人触发对象池回收并爆出金币，金币进入车身吸引范围后平滑滑向车身。
- [x] 波次时间结束时，画面弹出波次完成提示并平滑切入得来速进站流程。
- [x] 同屏 40 个敌人、80 发弹丸、上百粒子时稳定保持 60 FPS，无内存持续暴涨现象。

## 阶段 3：得来速进站商店与麦当劳 MCP 真实集成

### 🎯 目标愿景
将麦当劳官方 MCP 的真实门店、真实菜单与真实计价无缝映射为波次间的武器强化与修整系统。打造"把真实汉堡薯条装上赛车"的极客浪漫。

### 🛠️ 技术边界与约束
1. **进站交互流程**：
   - 波次结束前 3 秒，前方道路右侧出现闪烁的金色拱门得来速入口标志。
   - 车辆自动减速变道滑入得来速停靠位，战斗完全暂停。
   - 商店界面展开：包含 3 张由真实 MCP 驱动的餐品武器卡 + 1 个基础车辆维修选项。
2. **MCP 数据隔离与白名单**：
   - 前端通过 `/api/snapshot` 一次性获取全局快照，比赛中不发起任何轮询。
   - 复用 `reference/CODEX_REUSE_GUIDE.md` 提供的 6 个 MCP 白名单工具及计价过滤。
   - 绝不调用任何涉及下单、支付、领券、核销的接口。
   - 若本地未配置 `MCDONALDS_MCP_TOKEN`，自动降级为完全自包含的 `demoSnapshot` 示例模式。
3. **武器构筑深度**：
   - 遵循 `docs/WEAPONS_CATALOG.md` 的映射规范：
     - 汉堡类 → 巨炮、直线贯穿
     - 薯条类 → 扇形散射、弹幕压制
     - 饮品类 → 冰冻减速、环形气泡推力
     - 咖啡/甜品类 → 被动移速加成、车况护盾
   - 支持武器同名合成（Lv.1 → Lv.2 → Lv.3），6 槽满载时支持拖拽/点击替换。

### ✅ 验收标准
- [ ] 进站过渡动画自然平滑，战斗状态彻底冻结。
- [ ] 商店清晰展示 3 个餐品卡片：真实商品名、虚拟价格、对应车载武器类型与等级。
- [ ] 点击购买扣除金币，武器立即装备到底部 6 格武器栏中并在下一波生效。
- [ ] 当装备已有同款武器时，卡片明确标识“可升阶”并预览新技能特性。
- [ ] 支持金币维修车辆恢复车况。
- [ ] 出站时车辆获得 2 秒无敌涡轮加速喷射冲入下一波。
- [ ] 在断网或无 Token 环境下仍能流畅体验示例数据。

## 阶段 4：完整闭环、BOSS 战与商业级体验打磨

### 🎯 目标愿景
串联从标题启动、赛车选择、正式作战、BOSS 攻坚、车况耗尽抛锚到战绩结算的完整生命周期，消除所有死角与体验断层。

### 🛠️ 技术边界与约束
1. **完整状态机闭环**：
   - `TitleScene`：动态滚动的背景公路 + 标题浮动动画 + 开始按钮。
   - `SelectScene`：选择 3 款特色赛车（闪电红车、寒冰蓝车、磁力金车，各有独特初始被动）。
   - `GameScene` / `ShopScene`：波次推进与进站构筑。
   - `ResultScene`：最终抛锚停靠动画、总里程数、消灭数、最高连击数、6 个武器终局展示、重新开始。
2. **精英怪与 BOSS 机制**：
   - 第 5 波出现“双车道重型霸王卡车”：具备专属大血条、侧向冲撞震慑与后方投掷障碍物能力。
   - 击杀 BOSS 时触发全屏 0.2 秒时间缩放（Bullet-time）+ 白色高光闪烁 + 爆发性金币掉落。
3. **连击（Combo）与反馈体系**：
   - 连续消灭敌人触发屏幕右侧 Combo 计数跳动放大特效。
   - 车况低于 20% 时触发红色警示呼吸框与警报蜂鸣。
4. **持久化与断点续玩**：
   - 采用 `localStorage` 保存当前局内状态（波次、车况、金币、武器槽位、MCP 快照）。
   - 页面误刷新或切出后台可自动暂停并提供“继续游戏”入口。

### ✅ 验收标准
- [ ] 能够完整跑通：开局选车 → 倒数 3-2-1 → 多波次战斗 → 击败第 5 波 BOSS → 战损结算 → 一键再来一局。
- [ ] 全程无死循环、无未捕获 Promise Rejection、无黑屏卡死。
- [ ] 屏幕震动、伤害飘字、连击跳动、音效配合节奏紧凑，爽快感充足。
- [ ] 桌面端（键盘）与移动端（触摸屏竖屏）均具备完整的可玩性。

## 阶段 5（可选扩展）：进阶玩法与深度体验

### 🎯 目标愿景
在核心玩法稳固闭环后，接入深度 MCP 活动联动、更多奇特餐品武器与挑战模式，丰富长期游玩乐趣。

### 🛠️ 技术边界与约束
1. **更多进阶武器**：
   - 追踪类：麦辣鸡腿堡制导飞弹（自动追踪最近敌人）。
   - 环绕类：甜筒护盾（2~3 颗冰淇淋球围绕车身高速旋转，粉碎近身小怪）。
   - 召唤类：开心乐园餐（召唤一辆微型 AI 玩具僚车在侧翼提供辅助火力）。
2. **麦当劳优惠券系统（`query-store-coupons`）**：
   - 商店顶部展示当天可用的真实优惠说明（如“满减折扣”、“特定单品半价”）。
   - 动态计算原价划线与实付虚拟金币，给玩家真实的“薅羊毛”策略感。
3. **活动日历主题副本（`campaign-calendar`）**：
   - 当 MCP 命中官方活动时，特定波次更换主题贴图、敌人造型（如节日帽子）与专属加成。
4. **每日挑战与本地排行榜**：
   - 固定随机种子的每日无尽跑图模式。
   - 本地 `localStorage` 记录最远里程与 Build 殿堂。

### ✅ 验收标准
- [ ] 优惠券能在商店正确应用折算虚拟价格。
- [ ] 开心乐园餐僚车能跟随玩家赛车并协同射击。
- [ ] 进阶武器逻辑无报错且符合平衡性上限。
