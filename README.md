# 🏎️ Drive-Thru Survivors · 得来速幸存者

> **麦当劳赛车 × 土豆兄弟 × 得来速武器改装**
> 一款融合街机漂移赛车、Brotato 式自动射击生存和麦当劳 MCP 真实数据的网页游戏。

## 项目概述

开着赛车冲过敌群，用麦当劳餐品改装你的车载武器，看看你能在这条无尽公路上活多久。

- **赛车操控**来自《马里奥赛车》：漂移蓄力加速、碰撞弹飞、速度感十足
- **战斗系统**来自《土豆兄弟 Brotato》：自动射击、波次生存、波间商店、6 槽武器 Build 构筑
- **数据驱动**来自麦当劳 MCP：真实餐品变身车载武器，真实门店变身赛道站点

## 当前实现：阶段 0–2

点击「发动引擎」进入公路波次生存战。玩法分工为「前方开车避障、后方炮台清追兵」。车尾散弹炮每 0.38 秒向 360 道路单位内最近的疯狂骑手自动发射 3 颗弹丸，每颗伤害 12，预判移动并独立旋转瞄准；骑手绕到侧面或超过车头仍可继续锁定。炮台不主动清除路锥和购物车，弹速额外获得车速的 30%。首波 45 秒，此后每波增加 3 秒、上限 60 秒。倒计时结束后清场、发放波次奖励，赛车在 1.5 秒内自动减速靠右停站；点击「驶入下一波」继续，补充 20 氮气。餐品改装商店留待阶段 3。默认开启自动油门，可以关闭后使用 W / ↑ 加速；S / ↓ 刹车，A D / ← → 转向。按住 Shift + 转向开始漂移，可保持 Shift 并反打方向控制走线；松开 Shift 释放蓝 / 橙 / 紫三级加速。空格冲刺消耗 20 氮气并持续 2 秒；重新开局可补满车况与氮气。

桌面端保留竖向视角，游戏区接近占满可用高度，底部不显示触控按钮；漂移蓄力状态与自动油门位于左侧。移动端游戏铺满动态视口，页面无滚动，按安全区留出操作空间；支持多点触控，底部方向、减速、漂移和冲刺按钮高度为 64 CSS px。P / Esc 暂停，R 重置，M 切换声音；页面失焦或切到后台自动暂停，回到页面后手动继续。声音在首次交互后解锁，由 Web Audio 实时合成。

- 桌面使用 450×800 逻辑画布；手机保持 450 逻辑宽度，按屏幕比例扩展纵向场景。Phaser FIT 等比缩放，赛车不拉伸；WebGL 优先、Canvas 自动降级。
- 固定 60Hz 物理步长与位置插值；512 个预分配粒子精灵，饱和时丢弃新粒子。
- 由直道、长右弯、长左弯和连接段组成连续路线；道路曲率影响航向与速度相对道路的关系，保留轻度回正辅助。
- 道路、赛车、路边景物和粒子共用简易透视投影；碰撞在道路坐标中处理。路线进度独立于绘制，波次末由状态机控制进站。
- 赛车、树木、积木楼和门店纹理由代码绘制；配色、几何与音效包络参考关联项目，未引入外部图片、字体或音频。
- 路障锥静态阻挡、购物车横穿、疯狂骑手从后方追踪；命中闪白并浮出伤害数字，击杀爆破并掉落价值 1–3 的金币。路面金币进入车身 80 逻辑像素范围后自动磁吸；追兵战利品直接飞回车身，避免击杀发生在后方而无法领奖。
- 骑手以小队从车尾进入：前 15 秒每组 2 名，此后每组 3 名；有转向惯性，固定巡航速度约 394 道路单位/秒，冲刺能真正拉开距离。骑手车况 80；同一轮散弹近距离可集中命中 3 颗，远处通常仅中 1 颗，聚拢的追兵可以被同一轮散弹击中。前方路障单列生成，留出变道空间。赛车位置略向上移，并收紧上方仪表，为前方避障和车尾追击同时留出视野。
- 撞击伤害为 `36 × 当前绝对速度 / 340`；蓝 / 橙 / 紫漂移释放期间再乘 2 / 2.5 / 3，氮气期间乘 2，倍率取较高值。普通碰撞扣车况并给予 0.5 秒保护；冲刺撞击不扣车况，车况耗尽可重新开局。
- 弹丸 256、敌人 128、金币 128、粒子 512、伤害飘字 64 组均在开局预分配，池满不扩容；金币池满时合并掉落价值。飘字使用启动时缓存的数字位图，闪白纹理同时兼容 WebGL / Canvas。
- 弹丸使用固定空间网格粗筛和扫掠碰撞，避免高速穿透；战斗更新没有 `new`、对象 / 数组字面量或闭包创建。这里的零 GC 指游戏实体热路径无临时对象分配，Phaser、DOM 和浏览器仍可能进行内部内存分配和垃圾回收。
- 网关当前仅开放健康检查和配置状态，不连接 MCP；商店和真实快照按后续阶段实现。无需 Token 即可体验驾驶与战斗。
- `npm run dev` 提供只读 `window.__driveThru` 调试状态；生产构建不包含此接口。

阶段 0/1 验收覆盖桌面 Chromium、390×844 手机尺寸及多点触控模拟、强制禁用 WebGL 的 Canvas 路径。弯道原型另有路线接缝、投影与弯道物理检查。真机触感与扬声器听感仍需实际设备体验；固定物理步长不代表所有设备都已验证稳定 60 FPS。

### 阶段 2 验证

`npm test` 覆盖追兵索敌、后向弹道与射速、移动目标预判、冲刺拉开追兵距离、追兵战利品返还、高速弹丸单次命中、三类敌人、撞击倍率与保护、80px 磁吸、对象池满载、45 秒波次与进站、热路径分配检查以及 10 分钟模拟时间的对象池复用。`npm run build` 执行严格类型检查与生产打包。

开发模式访问 `http://127.0.0.1:5173/?stress=1` 并发动引擎可复现满载场景：持续补齐 48 个敌人、96 发弹丸和数百粒子，保留真实命中与掉落逻辑；此模式锁定车况、停止波次计时，仅用于性能检查。只读 `window.__driveThru.combat` 包含活跃 / 可见实体数与命中统计。该压测入口与调试接口不在生产模式启用。

2026-10-24 本机验证：Codex 内置浏览器 541×823 与 390×844 模拟视口，预热 120 帧后各采样 600 帧，均为 **60.00 FPS**，P95 帧时间 **<18ms**，>25ms 帧数 **0**；最小可见实体数分别为 **46 敌人 / 89 弹丸 / 481 粒子**、**48 / 96 / 480**。390×844 页面无横纵滚动，四个触控按钮高度均为 64 CSS px。高负载运行过程中，Chromium 强制 GC 后 JS 堆由约 29.5 MB 到 28.6 MB，未观察到持续增长。外部浏览器窗口被遮挡时存在约 30 FPS 的呈现限速，应在可见前台复测；以上结果不代表所有真机均已完成性能验收。

波次进站浏览器检查使用 QA 注入将首波缩短到最后 1 秒，确认停车后进度 / 金币冻结、奖励仅发一次，以及点击继续进入 48 秒的第 2 波；真实首波 45 秒与后续 60 秒上限由固定步长测试覆盖。上述注入仅发生在临时测试标签，不属于游戏代码。

另已强制禁用 WebGL，验证 Canvas 路径的自动射击、击杀、金币掉落与伤害飘字。

### 公路追逐生存原型

基础回合检验同一套后置散弹下的驾驶选择：变道避开障碍、引导有转向惯性的追兵聚拢、贴近提高散弹命中数、受压时冲刺拉开距离。手机可按住「减速」让追兵进入近距火力范围，桌面使用 S / ↓；需承担被追上的风险。HUD 根据距离提示「远距牵制」「近距散弹」或「追兵贴身」。后续不同武器再改变驾驶策略，当前不增加商店和装备种类。

`tests/prototype.test.ts` 使用相同的 45 秒波次、装备与真实驾驶物理对比两种脚本输入：一直直行约 41 秒耗尽车况；避障并在追兵贴近时使用冲刺可完成整波，剩余 55 车况。该结果是确定性模拟的玩法回归检查，不是玩家试玩结论。散弹另有近距 / 远距命中以及聚拢 / 分散追兵的对比测试。

散弹原型复测（2026-10-24）：34 项测试与构建通过。390×844 模拟视口下，预热后采样 600 帧，平均 60.00 FPS、P95 <18ms、>25ms 帧数 0；至少可见 48 敌人 / 96 弹丸 / 481 粒子，浏览器无错误或警告。五个触控按钮均高 64 CSS px，最窄约 55 CSS px；触摸按住减速实测速度约 302 → 111，释放后恢复至 207 并继续加速。仍需真人试玩判断聚怪、贴近和脱身的节奏是否有趣。
